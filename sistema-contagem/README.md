# Sistema de Contagem

Projeto desenvolvido em Python para realizar uma contagem utilizando número inicial, número final e incremento.

O sistema possui uma interface gráfica desenvolvida com Tkinter, permitindo que o usuário informe os valores e visualize o resultado da contagem.

## Como executar

1. Tenha o Python instalado.
2. Abra o terminal na pasta do projeto.
3. Execute o comando:

```bash
python contagem.py
```

## Como funciona

O usuário informa:

* Número inicial;
* Número final;
* Incremento.

Depois, basta clicar em **INICIAR CONTAGEM**.

O sistema realiza a contagem automaticamente e apresenta os números na tela.

## Tecnologias utilizadas

* Python
* Tkinter — utilizado para criar a interface gráfica
* `messagebox` — utilizado para exibir mensagens de erro

## Funcionalidades

* Contagem com incremento personalizado;
* Validação dos valores informados;
* Mensagens de erro;
* Botão para limpar os dados;
* Indicador de status;
* Atalho pela tecla Enter.
